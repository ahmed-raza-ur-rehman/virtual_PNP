# Virtual PnP - professional virtual SMD pick-and-place platform

A complete, open, verifiable pick-and-place platform: the machine model and
optimisers, the software that drives them, the firmware, the RTL that runs on
the FPGA, and the flow that turns that RTL into a checked GDSII layout - with
the verification evidence to go with it.

```
job file ─▶ optimiser ─▶ planner ─▶ simulator ─▶ control (RTL/firmware) ─▶ layout
   CAD       sequence     S-curve      digital        CSR/SPI/watchdog/     GDSII +
             feeder/tray  jerk-limited twin           encoder/limits       sign-off
```

## What is in the box

| Area | Content | Entry point |
| --- | --- | --- |
| Machine model + algorithms | placement/feeder/tray optimisation, S-curve planning, A*, vision, ML | `pnp/` |
| Applications | Typer CLI, FastAPI service, dependency-free web GUI | `python -m pnp.webgui`, `vpnp --help` |
| Web simulator | Three.js simulator with machine profiles and physics | `index.html`, `b.html` |
| Firmware | STM32 (FreeRTOS), ESP32, RP2040, AVR | `firmware/` |
| RTL | 3-axis motion, SPI/UART links, CRC framing, CSR, watchdog, limit monitor, vision moments | `rtl/` |
| Formal verification | SymbiYosys proofs with non-vacuity covers | `verification/formal/`, `make formal` |
| Netlist simulation | repository-owned cycle-accurate simulator + six testbenches | `tools/rtlsim/`, `make rtl-sim` |
| RTL-to-GDSII | synthesis, placement, routing, GDSII, DRC, connectivity, timing | `asic/miniflow/`, `make asic` |
| Native kernels | C++ (CTest), Rust, Go, hand-written x86-64 assembly | `cpp/`, `rust/`, `go/`, `asm/` |
| Documents | SRS, ICD, architecture, flows, trade-offs, V&V evidence, traceability | `docs/` |

## Quick start

```bash
./scripts/bootstrap.sh          # python env + pip-only EDA backend (WASM yosys)
make test                       # 26 software tests
make hdl-lint hdl-synth         # elaborate + synthesise every RTL block
make formal                     # SymbiYosys proofs (z3)
make rtl-sim                    # simulate the gate netlists, dump waveforms
make asic                       # netlist -> GDSII -> DRC/connectivity/timing
make verify-all                 # all of the above, in order
python -m pnp.webgui            # operator console
```

`make bootstrap` needs nothing but Python 3.10+ and network access to PyPI: the
HDL and layout tools are installed as Python wheels (WASM builds of Yosys and
SymbiYosys), so the whole flow runs on a laptop with no OS packages, no licence
server and no multi-gigabyte PDK.

## Verification, not just testing

Verification here means evidence per level, all regenerated by the commands
above and collected in `docs/evidence.md`:

* **formal** - divider arithmetic, watchdog windows, limit latching and encoder
  monotonicity are *proved*, with reachability covers so a proof cannot pass
  vacuously;
* **dynamic** - six testbenches drive the synthesised gate netlists through
  their pins and check CRC check values, divider results against Python's
  integer division, UART framing, quadrature decoding and a full CRC-protected
  SPI command frame;
* **layout** - the emitted GDSII is read back, checked for DRC (width, spacing,
  via enclosure), compared net-by-net with the netlist and timed with an RC
  model.

The evidence found ten real defects before any hardware existed - a broken
divider algorithm, two watchdog window bugs, a stop-path latency, two CRC
framing bugs, a pin-column short and more.  They are listed with the property
that caught each one in `docs/evidence.md`.

## Honest status

The platform reports its own gaps instead of hiding them (`docs/evidence.md`
§7, `docs/TRACEABILITY.md` *Gaps*): routing closure on the larger blocks is
90-99 % and the unrouted nets are named; the layout connectivity extraction
needs a second pass; clock/reset trees are not implemented, so the timing
numbers are optimistic.  Everything else in the table above is verified by a
command in this repository.
