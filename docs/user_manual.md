# User Manual

## Getting Started
1. Power on the machine.
2. Home all axes.
3. Load feeders.
4. Load PCB.
5. Run calibration.
6. Start job.

## Modes
- Manual: jog axes, pick/place manually.
- Semi: assisted placement.
- Auto: fully automatic.
- AI: optimized sequencing.

## Safety
- Emergency stop button.
- Light curtain.
- Collision detection.
